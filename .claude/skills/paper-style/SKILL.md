# paper-style
Use when writing or editing anything in paper/.

- One headline finding (RQ1). Everything else is supporting or future work.
- Frame as audit/measurement study, not broad claims about model welfare.
- Scope limits verbatim from proposal §15 — never soften them.
- "no measurable difference in this sample", never "absent" or "no effect".
- Every number in text must trace to analysis/ output; no numbers from memory.
- Methods must be reproducible from the text alone: cite the prereg tag hash,
  ladder release, judge rubric.
